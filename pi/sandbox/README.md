# pi/sandbox

统一的本地命令执行边界：`exec` 类工具经由本包执行，而非直接起子进程。

- `Host`：直接在宿主机执行的后端（可信/开发场景）。
- `Seatbelt`（macOS）、`Bubblewrap`（Linux）：基于系统沙箱机制的隔离后端。
- 写围栏（write policy）：与文件工具共享同一份工作区配置，命令执行与文件写入的允许范围保持一致。
- 进程管理：进程组归档与清理，避免孤儿进程。

选择哪个后端由上层按平台与配置决定；本包只提供执行边界本身。

当前状态：接口与后端都还没实现。`pi/tools/impl` 的 `bash` 工具暂时直接起子进程
（`exec.CommandContext`），尚未接入本包。
